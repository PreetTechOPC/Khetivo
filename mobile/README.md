# Khetivo Mobile App (React Native & Expo)

Official mobile application for Khetivo Smart Agriculture, tailored for Indian farmers with quick-action card buttons and all dashboard functionalities.

---

## 🌾 Key Features Included

1. **Quick-Action Button Cards on Home**:
   - High-contrast, tactile 3-column launcher grid with live indicators.
   - Quick access to all 12 platform tools: Soil & Water, Crop Guide, AI Leaf Scanner, Mandi Rates, Tasks, Inventory, Farm Ledger, Machinery, Parcels, Team, and Helpline.

2. **Soil & Irrigation Telemetry**:
   - Real-time parcel root-zone moisture tracking (with critical alert thresholds).
   - Remote 10HP Submersible Borewell automation timer with auto-cutoff.
   - PAU Alternate Wetting & Drying (AWD) water-saving recommendations.

3. **Crop Management & Standardized Packages**:
   - Rabi & Kharif crop profiles (Wheat, Paddy/Rice, Mustard, Potato).
   - Growth stages timeline with water sensitivity indicators.
   - **Recommended Do's & Crucial Don'ts strictly in clear bulleted points**.
   - Common diseases & PAU-approved spray protocols with exact chemical dosages per acre.

4. **Live APMC Mandi Rates**:
   - Government APMC mandis across Punjab and Haryana (Khanna, Ludhiana, Sirsa, Karnal, Rajpura, Jalandhar).
   - Crop filtering, modal prices, daily ranges, MSP comparison (+/- vs MSP), and price trends.

5. **AI Leaf Doctor & Diagnostic Scanner**:
   - 5-second neural leaf pathology diagnosis.
   - Instant confidence score, severity rating, and PAU chemical spray prescription.

6. **Field Tasks & Worker Delegation**:
   - Daily farm operational checklist with priority badges.
   - Assign operations to farm hands, mark completed, and create new field tasks.

7. **Inventory & Farm Store**:
   - Stock tracking for Neem-Coated Urea, DAP, Zinc Sulphate, fungicides, and diesel.
   - Low-stock reorder alerts and store valuation.

8. **Farm Financial Ledger (P&L)**:
   - Revenue vs Operational Expenses.
   - Real-time Net Farm Profit calculation.
   - Record new income/expense entries on the go.

9. **Equipment & Machinery Fleet**:
   - Tractors, Boom Sprayers, Laser Levelers, Submersible Motors.
   - Engine hours tracking, maintenance reminders, and fuel levels.

10. **Multi-Farm GPS Holdings**:
    - Switch seamlessly between holdings (Haveli Main Farm, Canal Road Holding).
    - Acreage, soil classification, and irrigation methods.

11. **Workforce & Quick Call**:
    - Directory of farm workers, tube-well operators, and tractor specialists with 1-tap dialer.

12. **PAU Agronomist Helpline**:
    - 1-tap toll-free helpline (1800-889-KHETI).
    - Direct WhatsApp chat link for instant video/photo consultations.

## 🚀 How to Run the App

Navigate to the `mobile` folder:

```bash
cd mobile
```

### 1. Start with Expo (Android / iOS / Web)
```bash
npm start
```

### 2. Run on Android Device / Emulator
```bash
npm run android
```

### 3. Run on iOS Simulator
```bash
npm run ios
```

### 4. Run in Browser (Expo Web)
```bash
npm run web
```
